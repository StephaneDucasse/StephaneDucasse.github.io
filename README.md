## Lessons learned
I write here some remarks to avoid mistake in the future. I hope that it will help someone. 
- first mistake, when I created my GH repo I was not aware of the page hosting service and the mapping of the URL to the name (not sure it existed) so I named it `Ducasse` instead of `StephaneDucasse`
- second mistake, I did not reacted or was smart enough to activate on time the `double authentification`  for git account on this account so now I cannot do it and got stuck. My problem was that I believed that I was able to commit with this account but I committed from another one. 
- third mistake, do not believe that large organisation can react to strange case like this one. I opened a ticket to get some help and guess what? no help!
